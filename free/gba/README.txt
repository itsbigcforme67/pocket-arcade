Games in this folder come with the site: they are published, and the gba/ page lists them under
"Free game" with a download link. The list itself is the "free" block in gba/index.html.

Only put a game here if it is yours to give away, or its licence allows it. Anything else belongs
in roms/gba/, which is never published.

dungeon.gba   Two-Floor Dungeon, a tech demo: a dungeon on two floor heights in tilted pseudo-3D,
              with a player. D-pad walks, A jumps (onto platforms, across or under bridges),
              B toggles zoom, L/R orbit, Select raises and Start lowers the camera; it orbits by
              itself until a button is pressed. Built from the GBA two-floor engine project
              (rom-c/dungeon-c.gba there); to update it, replace this file.
