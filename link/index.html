Link Cable

Two Game Boys joined by a link cable: on one screen, in two tabs, or on two phones.

One screen

Each half has its own controls, so two people can play on one phone or tablet.

Two screens

Each player sees their own Game Boy. Both screens run both Game Boys and send each other only the buttons, so the cable between them behaves exactly as on one screen.

Game:Tricky Wicks

Link two phones

One phone starts and shows a code; the other joins with it and shows a code back. No server is involved: the phones talk to each other directly, so put both on the same Wi-Fi (or one phone's hotspot).

Show this to the other phone

Enter the other phone's code

Tricky Wicks: on both Game Boys choose 2P LINK and press A, then press START on one of them.

Keys: left Game Boy ←↑→↓ X A Z B Enter Start Backspace Select; right Game Boy W A S D G A F B T Start R Select. On two screens either set works.

Games you open stay on your devices; nothing is uploaded to a server. On two screens the game itself never travels either: both players open the same file, and only buttons and the starting state go from one to the other. Battery saves are kept in this browser, one per Game Boy; Save and Load keep one save state of both Game Boys per game.

This page runs SameBoy (MIT licence) built for the browser by Pocket Arcade, with its link cable and infrared port wired up. It is part of a plan to connect devices to each other: see DEVICE_LINKS.md.
