Link Cable

Two Game Boys on one screen, joined by a link cable. Each half has its own controls, so two people can play on one phone or tablet.

Tricky Wicks: on both Game Boys choose 2P LINK and press A, then press START on one of them.

Keys: left Game Boy ←↑→↓ X A Z B Enter Start Backspace Select; right Game Boy W A S D G A F B T Start R Select.

Games you open stay on this device; nothing is uploaded. Battery saves are kept in this browser, one per Game Boy. There is no sound yet.

This page runs SameBoy (MIT licence) built for the browser by Pocket Arcade, with its link cable wired up. It is the first piece of a plan to connect devices to each other: see DEVICE_LINKS.md.
